# Хоккей — планировщик матчей

PWA: ставится на телефон как приложение, работает офлайн, данные хранятся только на этом устройстве.

## Что умеет

- **День**: неделя полосой, точка на днях с матчами, список по времени, фильтр по категории.
- **Категории**: 🎟 иду · 📺 смотрю · 📖 почитать · ✅ было · 🚫 мимо.
- **Всё**: список по датам, поиск, переключатель «предстоящие / прошедшие / все».
- **Лиги**: предзаготовки КХЛ, МХЛ, ВХЛ, NHL, WHL, OHL (чипами в форме). Свою лигу можно вписать вручную.
- **Переносы**: при смене даты сохраняется история, на карточке метка «↗ перенос с ...».
- **Наложения**: ⚡ если два матча в один день пересекаются по времени (матч считается 2,5 часа).
- **Напоминания за час** до матчей «иду» и «смотрю» со временем:
  - в приложении: нужно включить в «Данных» (разрешение на уведомления);
  - в календаре: экспорт .ics содержит VALARM за 60 минут. Это надёжный вариант, работает даже при закрытом приложении.
- **Экспорт .ics** и **копии .json** (скачать / загрузить).

## Установка (Android, Chrome)

1. Открой приложение по ссылке (GitHub Pages или любой статический хостинг).
2. ⋮ → «Установить приложение».
3. Открой «Данные» → «Напоминания» → «Включить» и разреши уведомления.

На iPhone: Safari → «Поделиться» → «На экран Домой». Уведомления для веб-приложений работают только после добавления на экран Домой и iOS 16.4+.

## Честно про напоминания

Веб-приложение не может гарантированно разбудить себя с закрытой вкладкой. Поэтому:
- уведомления из приложения работают, пока телефон не усыпил браузер; при возврате в приложение расписание пересчитывается;
- для надёжности экспортируй .ics и импортируй в календарь телефона: там напоминание сработает точно вовремя.

Матчи, которые начинаются раньше чем через час, напоминания не получают (момент уже в прошлом).

## Файлы

```

sw.js           офлайн-кеш и обработка клика по уведомлению
manifest.json   параметры установки
icons/          иконки
```

## Данные

`localStorage`, ключ `hockeyPlanner.v1`. Событие:

```json
{ "id": "e1", "date": "2025-10-19", "time": "19:30", "league": "КХЛ",
  "home": "Спартак", "away": "ЦСКА", "note": "", "status": "attend",
  "history": [], "created": "...", "updatedAt": "..." }
```

`status`: `attend` | `watch` | `read` | `done` | `skip`.
